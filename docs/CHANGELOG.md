# 更新日志

## v1.1.0
* **加载**：改用 `override.cfg` 把 mod 注册为 autoload —— 游戏自己重启后禁用 ModLoader 的那个实例也能加载
* **输入**：改用 `Input.is_key_pressed()` 轮询按键，不再依赖 `_input` 事件（曾被游戏节点消费掉）
* **ESC**：加入轮询队列，菜单可随时用 ESC 关闭
* **免费商店 / 免费刷新**：发现 1.1.x 的商店价格字段是「按玩家分的数组」，
  改为逐个玩家写入（`_reroll_price` / `_free_rerolls`），并同步刷新按钮上的价格显示
* **稳定性**：修复 GDScript 严格类型推断导致的编译失败；增加「自定义函数调用完整性」静态检查思路
* 调试：新增 `[key]` / `[toggle]` / `[shop]` 全链路埋点日志
* 文档：新增 `docs/LESSONS.md`（后期踩坑与最终方案）

## v1.0.0
* 初始发布
* 功能：无限金币、无限经验、免费商店、免费刷新、无敌、自动回满血、生命上限 999999、无限吸血、无限冷却、自动清怪
* 操作：清空本波敌人、立刻结束本波、全部关闭、关闭面板
* 中文界面、居中面板、ESC 关闭菜单
* 附带 `tools/pck_patch.py`（把 mod 直接写进 Brotato.pck，不依赖 Steam 创意工坊）
* 附带 `tools/build_zip.py`（打包 ModLoader zip）
